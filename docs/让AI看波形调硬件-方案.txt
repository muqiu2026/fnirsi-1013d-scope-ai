================================================
让 AI 看波形、帮你调试硬件 —— 完整方案
================================================

【先说清楚一个现实】
AI 对话是"一问一答"，没法真正 7x24 盯着实时波形流。
但调试硬件根本不需要连续实时——你只要把"有问题的那一刻"的波形
发给 AI 看，AI 就能分析。所以正确做法是"抓帧 → 发给 AI"，不是"实时流"。

================================================
方案 1：截图给 AI 看（最简单，强烈推荐先试这个）
================================================
步骤：
  1. 示波器上调好要观察的信号
  2. 按 CTRL 切换按钮页，找到 SAVE PIC（保存截图）→ 存到 SD 卡
  3. 示波器菜单 → USB Connection → 电脑识别为 U 盘
  4. 把 SD 卡里的 .bmp 截图拷到电脑
  5. 直接把图片发到对话里给我（就像你之前发拆机照片那样）

  我能从截图里看出：波形形状、幅值、频率、噪声、毛刺、削顶、触发稳定性等。

  优点：零配置，所见即所得，AI 直接看图
  缺点：要手动拷文件

================================================
方案 2：波形数据文件 → AI 分析报告（精确数值）
================================================
步骤：
  1. 示波器按 SAVE WAVE 保存波形数据到 SD 卡（.wav 文件，其实是二进制不是音频）
  2. 拷到电脑，比如放到工作区目录
  3. 运行工具：
       python wave2ai.py 你的波形文件.wav
  4. 工具会生成 3 个文件：
       xxx_AI报告.txt   → 中文文字报告（通道参数/幅值/频率/触发状态）
       xxx_波形.svg     → 波形图
       xxx.csv          → 每个采样点的原始数据
  5. 把 AI报告.txt 的内容（或截图+报告）发给我

  优点：有精确数值，适合分析频率/幅值/占空比/噪声
  缺点：需要跑一条命令

【工具位置】工作区 wave2ai.py（纯 Python，无需安装任何库）

================================================
方案 3：WaveGlance 深度分析（功能最全）
================================================
  位置：firmware\waveglance-v0.34.0-windows-x64\WaveGlance.exe
  把 SAVE WAVE 的 .wav 文件拖进去，可以看 FFT、游标、15项测量、协议解码。
  用它的"Export CSV"导出数据，或截图，再发给我。

================================================
实际调试工作流（推荐）
================================================
  1. 你接好电路，示波器调出波形
  2. 发现波形不对（比如有振荡/削顶/噪声）→ 按 SAVE PIC 截图
  3. 把截图发到对话里，并告诉我：
     - 这是什么电路/信号（比如"MCU 的 3.3V 电源纹波"）
     - 预期应该是什么样
     - 实际测到什么现象
  4. 我结合波形和电路知识帮你判断可能原因
  5. 需要精确数值时，再补一个 SAVE WAVE 文件用方案 2 分析

【我能帮你分析什么】
  - 电源纹波/噪声是否过大
  - 信号完整性：过冲、振铃、边沿速率、反射
  - 晶振起振、时钟信号是否正常
  - PWM/通信波形（UART/I2C/SPI）时序
  - 放大器/滤波器响应的波形形状
  - 触发不稳、间歇信号的问题

【给 AI 的信息越具体，分析越准】
  截图 + 电路描述 + 预期行为 + 测量点位置 + 示波器档位（V/div、时基）
  这五样齐全，判断准确度最高。
