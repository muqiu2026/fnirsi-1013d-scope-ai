# 硬件与芯片 · Hardware & SoC

## 示波器
- 型号：**FNIRSI 1013D**（部分固件/标称写作 **ADS 1013D**）
- 类型：平板式双通道示波器，标称 **100 MHz** 带宽
- 通道：CH1 / CH2

## 主控 SoC
- **Allwinner F1C100S**
- CPU 内核：**ARM926EJ-S**（ARMv5TE），本项目工具链以 `-mcpu=arm926ej-s` 编译并验证
- 主频：最高 408 MHz
- 显示控制器：DE（DEBE）层 0，帧缓冲常驻 RAM

## 屏幕 LCD
- 分辨率：**800 × 480**
- 色彩格式：**RGB565**（小端，标准 R5G6B5）
- 帧缓冲 `maindisplaybuffer` 大小：800×480×2 = **768,000 字节**
- `#SHOT` 即抓取此帧缓冲原始像素

## 模拟前端 / FPGA
- 采样由板载 FPGA 完成，原始 ADC 码 **0..255**，`128` 为该通道零点
- 电压换算：`V = (adc - 128) × (V/div) × 8 / 256`

## USB / 串口
- 改造固件启用 **USB CDC 虚拟串口**（菜单 "USB-Serial mode"）
- USB 标识：**VID 0x0483**（脚本据此自动识别端口）
- 端口示例：Windows `COM26`，Linux `/dev/ttyACM0`
- 波特率：**2,000,000**（兼容 921600 / 460800 / 115200），8N1，无流控
- 命令/应答行尾：`\n`

## 固件标识
- 版本串 `#VER` → `V1.3.0C MOD V9B4`
- 型号 `#INFO` → `#OK,1013D`

> 以上规格来自固件源码、改造说明与实机 `#VER`/`#INFO`/`#SHOT` 回读，非厂商宣传值。
