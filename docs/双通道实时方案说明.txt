================================================
双通道方案：电脑实时看界面 + AI 读懂示波器
================================================

【原理】
桥接程序 scope_bridge.py 做三件事：
  1. 监听示波器的 USB 串口（CDC），解析 #OK,<hex> 波形帧
  2. 写 live_scope.txt —— AI 读这个文件就能"看懂"示波器当前设置和波形
  3. 启动本地网页 http://localhost:8765 —— 你在电脑浏览器实时看波形

协议是从 web app 源码逆向出来的，已验证：
  - 帧格式: #OK,<ASCII十六进制>\n
  - 前 256 字节是参数（运行状态/时基/触发/通道档位/探头倍率...）
  - 后面是 CH1/CH2 原始采样字节
  - 电压档位表已按 web app 的 table_VPD 精确还原

【第一步：确认串口】
  在 Windows 命令行运行:
      python scope_bridge.py --list
  刚才扫描到:
      COM26  USB 串行设备 (COM26)   VID=1155 PID=22336  ← 这就是示波器(CH340芯片)
      COM21/COM22 是蓝牙串口，不要选

  ⚠ 如果 COM26 打不开报"权限"或"设备不识别"，说明串口被占用了：
     - 关掉正在运行的 web app / Chrome 里的那个页面
     - 关掉其他可能占用串口的程序
     - 重新插拔 USB 线

【第二步：启动桥接器】
      python scope_bridge.py COM26
  或指定波特率:
      python scope_bridge.py COM26 --baud 2000000

  启动后保持这个窗口开着。

【第三步：看界面 + 给 AI 读】
  - 你看的界面：浏览器打开 http://localhost:8765
      实时显示 CH1(黄) / CH2(蓝) 波形 + 示波器设置面板
  - AI 读的文件：工作目录下 live_scope.txt
      每帧自动更新，内容示例：
        运行状态: RUN
        水平时基: 100 us /格
        触发: AUTO / RISING沿 / 源=CH1
        CH1: 2.0 V/div, DC耦合, 10X探头
        CH1: Vpp≈11.25 V, 频率≈25 kHz, ...

【怎么用 AI 帮你调硬件 —— 纯数据分析，不用截图】
  live_scope.txt 里是完整的结构化数值，AI 直接推理，不需要图像识别：

  1. 桥接器开着，发现波形异常
  2. 对我说："读一下 live_scope.txt 帮我分析" —— 我会读到：
     - 仪器设置：运行/时基/触发/各通道档位耦合探头
     - 每通道波形指标：形状判断(方波/正弦/脉冲)、Vpp/Vmax/Vmin、
       直流均值、RMS、交流有效值、频率、占空比、上升时间、
       高频噪声、跳变沿数、原始ADC范围
     - 200点降采样波形数组（保留极值/毛刺）—— AI 直接读数组看波形形状
     - 自动异常提示（噪声过大/直流偏置异常/上升沿过快等）
  3. 你把电路情况和预期告诉 AI（如"这是MCU的3.3V电源，应该很干净"），
     AI 结合数据就能判断：幅值对不对、频率对不对、噪声大不大、
     有没有削顶/振荡/毛刺、直流偏置是否异常。

  用数据而不是截图的好处：精确、快、AI 能做数值推理（比如算出
  噪声占 Vpp 的百分比），不受图像分辨率/压缩影响。

  网页 http://localhost:8765 只是给你自己看波形用的，AI 不需要它。

【已知限制】
  - 波特率如果不对会自动尝试，但某些固件用固定值；
    如果连上没数据，试 --baud 115200 / 921600 / 2000000
  - 桥接程序会主动发 #WAV2,1 请求波形帧（轮询），
    和 web app 一样，所以两个别同时开（抢串口）
  - 电压换算基于 web app 的档位表，精度够判断硬件问题，
    精确测量仍以示波器自身读数为准

【文件清单】
  scope_bridge.py        桥接程序（主程序）
  live_scope.txt         AI 可读实时数据（自动生成/更新）
  wave2ai.py             离线波形文件分析工具（SAVE WAVE 用）
  网页地址               http://localhost:8765
