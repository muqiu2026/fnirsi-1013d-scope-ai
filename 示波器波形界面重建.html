这次修正了什么（旧版重建错在哪）
1. 频率差 3 倍：旧版用「时基×10格÷3000点」反推每点时间，得 3kHz。固件真实采样率由 time_per_div_sample_rate[20] → sample_rate[8] = 500KSa/s（2us/点）， 500 点周期 → 1.00kHz，与截图 Freq / Cycle / Time± / Duty 六项全部吻合。
2. 周期数差一倍、波形变成粗黄带：#WAV2,3 的 3000 点是采集缓冲 （后 1801 字节是 0x80 填充）。屏幕宽 726px，按 disp_xpos_per_sample = 50×5000/500000 = 0.5px/点、disp_sample_step = 2 跳着取样，只用 1452 个采样点画 726 个输出点，一屏约 2.9 个周期。 缓冲区是两路交织 ADC（162/148 交替），旧版逐点全画既多出一倍周期， 又把平顶画成粗黄块；步长 2 抽样后才是真机上的细线方波。
3. 网格格数错：固件 scope_draw_grid() 是 50px 一大格、宽 726px、中心 x=364/y=249， 即横向 14.5 格；旧版硬编码 10 格。
4. 波形上下位置错：通道零点应按 scope_draw_pointers() 的 y = 441 - traceposition，且 ADC 越大越靠屏幕上方； 旧版符号和基准都反了。
5. Vpp 被野点撑大：采样帧偶发 6/252 之类野点，min/max 法算出 7.8V。 改成「高/低电平平台中位数」后稳定在 3.09～3.47V，与截图 3.44V 一致。
6. 界面元素缺失：旧版只有一条状态文字；这版补齐顶部状态栏、右侧 8 个菜单按钮、 4×3 测量面板、底部波形总览条与选区框、绿色触发位置箭头、青色 T 游标、黄色 CH1 基线箭头。
7. 幅度类需要一次真机标定：#WAV2,3 返回的是 FPGA 原始 ADC （两路交织，要按步长 2 分离 bank 再取平台），而屏幕测量面板走固件内部的 dcoffset / adc1compensation / dc_shift_size 校准链，这些量不在 #READ 的 320 字节里。按理论值（0.03125 V/ADC、零点 128）直接算会 偏小约 8%、直流偏约 1.2V。执行 python scope_ai.py calibrate 2.18 -1.32（屏幕上的 Umax/Umin） 标定一次即可对齐；换电压档 / 探头 / 耦合后会自动失效，需重新标定。
结论：暂停状态下时间类 5 项（Freq / Cycle / Time± / Duty） 与截图逐项完全一致；幅度类在标定后一致。Urms 与 Vavg 两项真机读数本身不自洽 （Vavg=-3.64V 落在 Umin=-1.32V 之外；3.48Vpp、50% 占空比的对称方波 RMS 应≈1.75V 而非 660mV），属于固件测量项定义问题，不是串口数据错。勾选「对齐截图直流」 只做纯视觉平移，不改动任何测量值。
