================================================
为什么 Web 界面很多按键没用？更好的替代方案
================================================

【根本原因 —— 我查了固件源码确认的】
Web 软件（FNIRSI1013D-APP beta10）本身是从 DSO2512G 的 APP 移植来的，
但 1013D 开源固件的 PC 控制命令几乎没实现。

我查看了 v0.27r / v0.28a 固件的 PC_interface.c 源码，
里面的命令解析函数 usb_CDC_process_rx() 只处理一个空的 "#ECHO" 命令
（而且实际代码被注释掉了）：

    void usb_CDC_process_rx(void) {
        ...
        if(strcmp(cmd_buf, "#ECHO") == 0) {
           // usb_ch340_send_data(...)   ← 被注释，什么也不做
        }
    }

结论：固件只实现了"把波形数据发给 PC"，没有实现"PC 控制示波器"
（切换档位、触发、RUN/STOP 等）。所以 web 界面上那些控制按键按了没反应，
是固件端根本不响应——换任何上位机软件都没用，除非有人重写固件。

Atlan 自己也在论坛说这个 APP "has bugs, but really big bugs"、
"If someone wants to play, otherwise don't use it"。

【所以现实是】
  ✅ 能用的：实时看到波形画面（START 后波形刷新）
  ❌ 不能用的：几乎所有远程控制按键（固件没实现）

================================================
推荐方案 A：WaveGlance（功能完整，强烈推荐）
================================================

这是目前最成熟的 FNIRSI 波形分析软件，功能碾压那个 web app：
  - 支持 1013D/1014D 的 .wav 波形文件（示波器 SAVE WAVE 存的）
  - 15 项自动测量（Vpp/Vrms/频率/占空比/上升时间...）
  - 时间/电压游标，FFT 频谱（5 种窗函数）
  - 数学通道 CH1+CH2 / CH1-CH2
  - UART / I2C / SPI 协议解码
  - 多文件叠加对比、参考波形
  - 导出 CSV / PNG 截图 / 打印
  - 有中文界面（🌐 按钮切换）

  位置：firmware\waveglance-v0.34.0-windows-x64\WaveGlance.exe（21MB，双击运行）
  官网在线版：https://afmiguel.github.io/waveglance/ （免安装，文件不上传）

  用法（离线分析，不是实时）：
    1. 示波器上按 SAVE WAVE 保存波形到 SD 卡
    2. 用 U 盘模式把 .wav 文件拷到电脑
    3. 拖进 WaveGlance → 完整分析

  注：SmartScreen 可能提示，选"更多信息 → 仍要运行"。

================================================
推荐方案 B：FNIRSI Wave Explorer（浏览器，功能全）
================================================
  https://github.com/jesuslg123/fnirsi-wave-explorer
  在线版可看 1013D 波形文件，支持叠加对比、FFT、游标、CSV 导出。
  同样需要本地 npm 构建或等作者发布在线版，比 WaveGlance 麻烦。

================================================
关于"实时"的现实
================================================
目前 1013D 生态里，实时波形显示只有那个 beta10 web app 一家，
而且只能看波形，不能远程控制（固件限制）。

如果实时+控制对你很重要，只有两条路：
  1. 等社区开发：Atlan 说"希望有人来写"（I hope someone writes it）
  2. 自己改固件：PC_interface.c 里加命令解析（需要 ARM 开发能力）
     源码都在 GitHub，固件是 GPL 开源

我的建议
================================================
日常用波形分析 → WaveGlance（方案A），功能完整、稳定、免费
想看实时波形 → 保留 web app，但只当它是"远程显示屏"，别指望按键控制
要中文界面 → WaveGlance 自带中文切换
